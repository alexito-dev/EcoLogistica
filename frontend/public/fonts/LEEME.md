# Fuentes

La interfaz usa **Codec Pro** (Regular 400, Semibold 600, Bold 700, ExtraBold 800).
Es una fuente comercial: coloque aquí los archivos con licencia:

- `CodecPro-Regular.woff2`
- `CodecPro-Semibold.woff2`
- `CodecPro-Bold.woff2`
- `CodecPro-ExtraBold.woff2`

Mientras no estén, la interfaz usa la fuente del sistema (`system-ui`).
