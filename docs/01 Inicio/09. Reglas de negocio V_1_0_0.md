# 09. Reglas de negocio y trazabilidad

[← Volver al README Principal](../../README.md)

| Código | Regla |
|---|---|
| RN-001 | Tres intentos fallidos bloquean la cuenta durante 15 minutos. |
| RN-002 | El cálculo de CO₂ usa el factor de emisión configurado para el combustible y conserva unidad y fuente. |
| RN-003 | Una ruta no puede exceder capacidad, turno ni ventana horaria sin marcar la violación. |
| RN-004 | Un pedido sin coordenada con confianza suficiente no puede publicarse en una ruta automática. |
| RN-005 | Todo cambio de estado registra actor, fecha, ubicación disponible y resultado. |
| RN-006 | Una incidencia publicada exige recalcular o justificar por qué se mantiene la secuencia. |
| RN-007 | La restricción de placa se aplica únicamente en los días y zonas parametrizados. |
| RN-008 | Los datos personales no se muestran en exportaciones destinadas a evaluación. |
