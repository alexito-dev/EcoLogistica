## 2. Propósito y método

Los RNF expresan condiciones medibles de calidad y restricciones transversales del PMV. Cada escenario adopta la estructura: **fuente del estímulo, estímulo, entorno, artefacto, respuesta y medida de respuesta**. Ningún término como “rápido”, “seguro”, “intuitivo” o “escalable” se considera criterio de aceptación sin una métrica y un método de prueba.

Para mantener coherencia con el catálogo funcional, RF-11.1 y RF-11.2 se tratan como requisitos **derivados** de seguridad y auditoría que amplían la línea base RF-01–RF-10. RNF-05 a RNF-08 cuantifican su calidad y no introducen un módulo de negocio adicional.

## 4. Perfiles de prueba y reglas de medición

| Perfil | Definición controlada |
|---|---|
| Datos PMV | Dataset sintético georreferenciado en el ámbito, sin datos personales reales |
| Caso nominal de optimización | 150 pedidos, 15 vehículos, depósito único, ventanas y capacidades válidas |
| Caso volumétrico | Hasta 1,000 pedidos y 50 vehículos; evalúa persistencia/consulta, no promete optimización ≤ 45 s |
| Red 3G degradada | 1.6 Mbps bajada, 750 Kbps subida, RTT 300 ms, pérdida 1 % |
| Red 2G extrema | 250 Kbps bajada, 100 Kbps subida, RTT 800 ms, pérdida 2 %; se exige modo conductor degradado |
| Dispositivo de campo | Android de gama de entrada, pantalla ≥ 360 × 640, 2 GB RAM, navegador vigente |

Los percentiles se calcularán después de una ejecución de calentamiento. Cada prueba de rendimiento registrará versión, infraestructura, dataset, número de repeticiones y evidencia. “No calculable” no se contabiliza como cero.

## 5. Prioridad y puerta de liberación

| Nivel | RNF | Condición |
|---|---|---|
| Bloqueante | RNF-01, 02, 05–12, 16, 17, 19 | Su incumplimiento impide etiquetar `v1.0.0` |
| Obligatorio | RNF-03, 04, 13–15, 20 | Debe aprobarse o contar con excepción formal, responsable y fecha |
| Optimización continua | RNF-18 | Se mide en cada iteración y no puede empeorar sin justificación |

## 7. Gestión de excepciones

Toda excepción deberá identificar RNF afectado, medición obtenida, causa, riesgo, compensación, responsable y fecha de cierre. No se aceptan excepciones para una violación de seguridad crítica, pérdida de integridad, exposición de datos personales o incumplimiento de una restricción dura del ruteo.
