## 2. Propósito y Justificación del Proyecto
DistriRápido S.A.C. enfrenta altos costos operativos, demoras en las ventanas horarias de entrega en última milla e impacto ambiental derivado del consumo excesivo de combustible fósil y emisiones de dióxido de carbono ($CO_2$).

El proyecto **EcoLogística** propone el diseño e implementación de un Producto Mínimo Viable (PMV) web capaz de resolver el Problema de Enrutamiento de Vehículos con Ventanas de Tiempo (VRPTW) y consideraciones ecológicas (Green VRP) mediante algoritmos metaheurísticos, ofreciendo asignación óptima de pedidos a flota/conductores, visualización geográfica en tiempo real, re-optimización dinámica ante contingencias y métricas auditables de huella de carbono.

---

## 3. Objetivos del Proyecto

### 3.1 Objetivo General
Desarrollar e implementar un Producto Mínimo Viable (PMV) de una plataforma web para la optimización de rutas de última milla considerando restricciones de capacidad, ventanas de tiempo y minimización de emisiones de $CO_2$ para la empresa DistriRápido S.A.C. en un plazo de 12 semanas.

### 3.2 Objetivos Específicos
1. **Módulo de Gestión:** Implementar la administración de pedidos, catálogo de flota vehicular (capacidades, tipo de combustible) y registro de conductores.
2. **Motor Metaheurístico:** Desarrollar un algoritmo de optimización para VRPTW y Green VRP que minimice la distancia total, el tiempo de recorrido y la huella de carbono.
3. **Cartografía y Visualización:** Integrar mapas interactivos para el trazado geoespacial de rutas optimizadas y puntos de parada.
4. **Métricas y Sostenibilidad:** Diseñar un dashboard con KPIs logísticos y reportes exportables de reducción de emisiones de $CO_2$.
5. **Re-optimización Dinámica:** Permitir el reajuste en tiempo real de rutas asignadas ante cancelaciones, nuevos pedidos o incidencias viales.

---

## 4. Alcance del PMV
- **Incluido en el Alcance:**
  - Plataforma Web con interfaz responsiva para despachadores y administradores logísticos.
  - CRUD de Pedidos, Flota de Vehículos y Conductores.
  - Motor de optimización de rutas (VRPTW & Green VRP).
  - Trazado de rutas y paradas sobre mapa interactivo.
  - Panel de control con indicadores de rendimiento y emisiones de $CO_2$.
  - Módulo de re-optimización ante eventos imprevistos.
  - Documentación de ingeniería bajo estándares PMI/Ágiles y Git Flow.
- **Excluido del Alcance:**
  - Aplicación móvil nativa para conductores (se empleará interfaz web responsive en el PMV).
  - Integración por hardware telemático OBD-II en tiempo real en los vehículos.
  - Pasarelas de pago para cobro a clientes finales.
