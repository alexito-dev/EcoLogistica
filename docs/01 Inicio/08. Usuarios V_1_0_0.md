# 08. Identificación y perfiles de usuarios

[← Volver al README Principal](../../README.md)

## 1. Roles y necesidades

| Rol | Objetivo | Interacción |
|---|---|---|
| Administrador | Configurar usuarios, flota y reglas | Directa, alta |
| Planificador / despachador | Cargar pedidos, generar y publicar rutas | Directa, alta |
| Conductor | Consultar secuencia y reportar estados/incidencias | Directa, móvil |
| Gerencia / Product Owner | Revisar KPIs y decisiones operativas | Directa, consulta |
| Auditor externo | Revisar trazabilidad sin modificar datos | Directa, lectura |
| Servicio de mapas | Proveer geocodificación/cartografía | Indirecta, sistema |

## 2. Historias de uso resumidas

- El despachador registra pedidos y confirma ubicaciones antes del corte diario.
- El planificador genera rutas y decide si publica o revisa la propuesta.
- El conductor consulta su ruta y reporta entrega o incidencia.
- La gerencia compara resultados contra la línea base y revisa el CO₂.
- El auditor exporta logs con acceso de solo lectura.

| Capacidad | Administrador | Planificador | Conductor | Gerencia | Auditor |

Se aplica mínimo privilegio y segregación de funciones; la identidad real se reemplaza por datos sintéticos en el entorno académico.
